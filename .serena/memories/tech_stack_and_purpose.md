# Tech Stack & Purpose
- **System**: Student Accommodation System
- **Purpose**: A multi-tenant SaaS platform for private building owners to list rooms and for students to find, apply for, and book accommodation.
- **Backend Stack**: Java 21, Spring Boot 3.5.7, PostgreSQL 16, Redis 7.4, MinIO.
- **Frontend Stack**: Angular 21, Angular Material, RxJS.
- **Build Tools**: Gradle (backend), npm/Angular CLI (frontend), Docker Compose.
