feat: Integrate notification system, error handling, and activity logs

## Summary
Integrated three major features into the application:
1. Notification system with auto-polling
2. Global error handling with HTTP interceptor
3. Activity logs viewer for admins

## Changes

### Notification System Integration
- Added notification bell icon to navigation bar
- Integrated NotificationService into auth flow
- Auto-start polling on login/signup
- Auto-stop polling on logout
- Displays unread count badge
- Dropdown menu with notification list

### Global Error Handling
- Converted ErrorInterceptor to functional interceptor pattern
- Registered in main.ts HTTP client configuration
- Automatic retry for failed GET requests
- Smart error message extraction from backend
- Auto-redirect on 401 (unauthorized) → login page
- Auto-redirect on 403 (forbidden) → unauthorized page
- Network error detection
- User-friendly snackbar notifications

### Activity Logs Integration
- Added /admin/activity-logs route
- Protected with AdminGuard
- Added menu items to admin navigation (mobile + desktop)
- Lazy-loaded for optimal performance
- Advanced filtering UI ready
- Pagination and export functionality ready

### Styling Enhancements
- Added error snackbar styles to global CSS
- Red gradient background for error notifications
- Ensures high visibility for user feedback
